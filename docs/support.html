LiveWall Support

Wallpaper says "Motion Not Available"

Set it from Settings → Wallpaper → Add New → Photos, choose the Live Photo, and make sure the Live button isn't crossed out. Low Power Mode also disables motion.

Notes aren't showing on my Lock Screen

Add the widget: long-press the Lock Screen → Customize → tap under the clock → LiveWall. Allow notifications for LiveWall. The widget can take a few minutes to refresh.

Restore my purchase

Open the Wallpaper tab → Restore Purchases.

Delete my data / report abuse

Partner tab → ⋯ → Delete my data, or Block… to block and report.
